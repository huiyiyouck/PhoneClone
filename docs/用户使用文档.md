# 多开助手 - 用户使用文档

## 简介

多开助手是一款Android应用多开管理工具，允许用户在同一设备上运行同一应用的多个实例，方便管理不同的账号。

## 功能特性

- 用户注册和登录
- 应用列表管理
- 应用多开实例创建和管理
- 数据云端同步
- 离线数据缓存

## 使用指南

### 1. 注册和登录

#### 注册账号
1. 打开应用，进入登录界面
2. 点击"立即注册"
3. 填写用户名、邮箱和密码（密码至少8个字符）
4. 确认密码
5. 点击"注册"按钮完成注册

#### 登录账号
1. 在登录界面输入邮箱和密码
2. 点击"登录"按钮
3. 登录成功后自动跳转到主页

### 2. 添加应用

1. 在主页点击"添加应用"按钮
2. 系统会显示所有已安装的应用列表
3. 选择需要多开的应用（可多选）
4. 点击右下角的"+"按钮确认添加

### 3. 创建多开实例

1. 在主页找到已添加的应用
2. 点击应用卡片
3. 点击"添加实例"按钮
4. 输入实例名称（如：工作账号、小号等）
5. 选择实例颜色标识
6. 点击"确定"创建实例

### 4. 启动/停止实例

1. 在应用实例列表中
2. 点击实例右侧的播放按钮启动实例
3. 点击停止按钮停止运行中的实例

### 5. 删除应用或实例

1. 长按应用卡片或实例项
2. 选择"删除"选项
3. 确认删除操作

## 注意事项

1. **多开功能说明**：应用使用VirtualApp框架实现多开，首次使用可能需要授权相关权限
2. **数据同步**：应用数据会自动同步到云端，支持多设备访问
3. **网络要求**：首次使用和同步数据需要网络连接，其他功能可离线使用
4. **性能影响**：运行多个应用实例会占用更多内存和CPU资源

## 常见问题

### Q: 为什么某些应用无法多开？
A: 部分系统应用或受保护的应用可能无法多开，这是Android系统的安全限制。

### Q: 多开实例的数据会互相影响吗？
A: 不会，每个实例都有独立的数据存储空间，互不干扰。

### Q: 如何切换账号？
A: 每个实例可以登录不同的账号，通过启动不同的实例来切换账号。

### Q: 数据会丢失吗？
A: 应用数据会同步到云端，即使卸载应用，重新安装后登录账号即可恢复数据。
