# 多开助手 - 开发文档

## 项目架构

### 整体架构

项目采用三层架构：

```
┌─────────────────┐
│  Android客户端   │  (Java 21)
│   MVVM架构      │
└────────┬────────┘
         │ HTTP/REST
┌────────▼────────┐
│  Spring Boot     │  (Java 21)
│  后端API服务     │
└────────┬────────┘
         │ JDBC
┌────────▼────────┐
│  PostgreSQL      │
│  云数据库        │
└─────────────────┘
```

### Android客户端架构

采用MVVM（Model-View-ViewModel）架构模式：

- **Model层**：数据模型、Room数据库实体
- **View层**：Activity/Fragment、UI布局
- **ViewModel层**：业务逻辑处理、LiveData数据绑定
- **Repository层**：数据仓库，统一管理本地和远程数据源
- **Network层**：Retrofit + OkHttp网络请求

### 后端服务架构

采用分层架构：

- **Controller层**：RESTful API接口
- **Service层**：业务逻辑处理
- **Repository层**：JPA数据访问
- **Entity层**：数据库实体模型
- **DTO层**：数据传输对象
- **Security层**：JWT认证授权

## 技术栈

### Android客户端

- **语言**：Java 21
- **UI框架**：Material Design Components
- **架构组件**：ViewModel, LiveData, Room
- **网络库**：Retrofit 2.11.0 + OkHttp 4.12.0
- **依赖注入**：Hilt 2.52
- **多开框架**：VirtualApp SDK（需集成）

### 后端服务

- **框架**：Spring Boot 3.2.0
- **数据库**：PostgreSQL
- **ORM**：Spring Data JPA
- **安全**：Spring Security + JWT
- **API文档**：SpringDoc OpenAPI

## 数据库设计

### 表结构

#### users - 用户表
- id: BIGSERIAL PRIMARY KEY
- username: VARCHAR(50) UNIQUE
- email: VARCHAR(100) UNIQUE
- password_hash: VARCHAR(255)
- membership_level: VARCHAR(20) (free/vip/svip)
- membership_expiry: TIMESTAMP
- avatar_url: VARCHAR(500)
- created_at: TIMESTAMP
- updated_at: TIMESTAMP

#### apps - 应用表
- id: BIGSERIAL PRIMARY KEY
- user_id: BIGINT (外键)
- package_name: VARCHAR(255)
- app_name: VARCHAR(255)
- icon_url: VARCHAR(500)
- category: VARCHAR(50)
- created_at: TIMESTAMP
- updated_at: TIMESTAMP

#### app_instances - 应用实例表
- id: BIGSERIAL PRIMARY KEY
- app_id: BIGINT (外键)
- instance_name: VARCHAR(100)
- color: VARCHAR(20)
- status: VARCHAR(20) (running/stopped)
- created_at: TIMESTAMP
- updated_at: TIMESTAMP

#### user_sessions - 用户会话表
- id: BIGSERIAL PRIMARY KEY
- user_id: BIGINT (外键)
- token: VARCHAR(500) UNIQUE
- expires_at: TIMESTAMP
- created_at: TIMESTAMP

## API文档

### 认证接口

#### 用户注册
```
POST /api/auth/register
Content-Type: application/json

{
  "username": "string",
  "email": "string",
  "password": "string"
}

Response:
{
  "token": "string",
  "username": "string",
  "email": "string",
  "membershipLevel": "string",
  "expiresIn": 86400000
}
```

#### 用户登录
```
POST /api/auth/login
Content-Type: application/json

{
  "email": "string",
  "password": "string"
}

Response: 同注册接口
```

### 应用管理接口

#### 获取用户应用列表
```
GET /api/apps
Authorization: Bearer {token}

Response: App[]
```

#### 创建应用
```
POST /api/apps
Authorization: Bearer {token}
Content-Type: application/json

{
  "packageName": "string",
  "appName": "string",
  "iconUrl": "string",
  "category": "string"
}

Response: App
```

#### 删除应用
```
DELETE /api/apps/{appId}
Authorization: Bearer {token}
```

### 实例管理接口

#### 获取应用实例列表
```
GET /api/apps/{appId}/instances
Authorization: Bearer {token}

Response: AppInstance[]
```

#### 创建实例
```
POST /api/apps/{appId}/instances
Authorization: Bearer {token}
Content-Type: application/json

{
  "instanceName": "string",
  "color": "string"
}

Response: AppInstance
```

#### 更新实例状态
```
PUT /api/apps/instances/{instanceId}/status?status=RUNNING
Authorization: Bearer {token}

Response: AppInstance
```

#### 删除实例
```
DELETE /api/apps/instances/{instanceId}
Authorization: Bearer {token}
```

## 部署指南

### 后端部署

#### 1. 环境要求
- Java 21
- PostgreSQL 12+
- Gradle 8.5+

#### 2. 数据库配置

1. 创建PostgreSQL数据库：
```sql
CREATE DATABASE phoneclone_db;
```

2. 配置数据库连接（application.yml）：
```yaml
spring:
  datasource:
    url: jdbc:postgresql://your-db-host:5432/phoneclone_db
    username: your-username
    password: your-password
```

3. 运行数据库迁移脚本：
```bash
# 脚本位于 backend/src/main/resources/db/migration/V1__init.sql
# Spring Boot会自动执行Flyway迁移
```

#### 3. 配置JWT密钥

在application.yml或环境变量中设置：
```yaml
spring:
  security:
    jwt:
      secret: your-256-bit-secret-key
```

#### 4. 构建和运行

```bash
cd backend
./gradlew build
./gradlew bootRun
```

或打包为JAR：
```bash
./gradlew bootJar
java -jar build/libs/phoneclone-backend-1.0.0.jar
```

### Android客户端部署

#### 1. 环境要求
- Android Studio
- JDK 21
- Android SDK 29+

#### 2. 配置后端API地址

在`RetrofitClient.java`中修改BASE_URL：
```java
private static final String BASE_URL = "https://your-api-domain.com/api/";
```

#### 3. 集成VirtualApp SDK

1. 将VirtualApp AAR文件放入`app/libs/`目录
2. 在`app/build.gradle`中添加依赖：
```gradle
dependencies {
    implementation files('libs/virtualapp.aar')
}
```

3. 在`MultiInstanceService.java`中实现具体功能

#### 4. 构建APK

```bash
cd app
./gradlew assembleDebug  # Debug版本
./gradlew assembleRelease  # Release版本
```

## 开发指南

### 添加新功能

1. **后端**：
   - 在`entity`包中创建实体类
   - 在`repository`包中创建Repository接口
   - 在`service`包中实现业务逻辑
   - 在`controller`包中创建API接口

2. **Android**：
   - 在`model`包中创建数据模型
   - 在`network/api`包中定义API接口
   - 在`repository`包中实现数据仓库
   - 在`viewmodel`包中创建ViewModel
   - 在`ui`包中创建Activity/Fragment

### 代码规范

- 使用Java 21特性
- 遵循Android开发最佳实践
- 使用MVVM架构模式
- 添加必要的注释和文档

## 常见问题

### Q: VirtualApp SDK如何获取？
A: VirtualApp是开源项目，可以从GitHub获取源码并编译为AAR，或使用第三方提供的SDK。

### Q: 如何调试后端API？
A: 使用Postman或Swagger UI（访问 http://localhost:8080/swagger-ui.html）

### Q: 数据库迁移如何处理？
A: 使用Flyway进行数据库版本管理，迁移脚本放在`db/migration`目录下。
